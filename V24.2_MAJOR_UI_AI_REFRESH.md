# Licia V24.2 — Major UI/AI Refresh

Based on licia-v23.6-ui-export-fix.

## Requested refresh
- Dashboard rebuilt as information-first personal home with clickable real data cards and no rail-only landing.
- Search rebuilt for dense, mobile-friendly result browsing.
- Guide rebuilt as a cleaner Help Center.
- Settings rebuilt with compact sections, restored export and mobile account access.
- Chat rebuilt as a normal modern chat surface; no persistent action-running strip; mobile menu is an overlay that cannot sit behind the chat stream.
- Mobile bottom navigation explicitly capped to four primary items plus More = five total.
- Universal AI action routing extended with a dedicated `delete_tasks_bulk` operation.
- Bulk task deletion uses one database delete operation and one review/approval instead of one-by-one deletion.
- Bulk task deletion is undoable through action history snapshots of tasks + subtasks.
- AI routing/system instructions updated so clear mass-delete task requests are routed to `delete_tasks_bulk`.
- PWA/mobile CSS hardened further.

## Validation performed in build container
- Source copied from V23.6 baseline.
- Script-level source audit and archive integrity checked.
- Full Next.js build is not claimed here because this environment does not have the user's installed project dependencies.

npm install

## Important behavior
With `aiConfirmMassive=true` (default), a request like “hapus semua tugas” should produce a single review card for the bulk action. Approval executes one `delete_tasks_bulk` call; it does not ask for each task.
