# Licia V23 — Major Life OS Upgrade

V23 adalah major upgrade non-integrasi: AI cross-module diperluas, UI/UX dashboard/chat/tasks/mobile/settings diperbarui, dan tiga feature surface baru ditambahkan.

## Fitur baru
- Life Command: command center natural-language untuk membaca konteks dan menjalankan action.
- Capture Studio: universal text/voice/image capture untuk Inbox/Task/Note.
- Life Pulse: operational snapshot + attention radar + recovery entry point.

## AI
- Routing `all` menambahkan seluruh read tools dan seluruh write tools saat request memang meminta aksi.
- System prompt menekankan unified Life OS graph dan verifikasi antar modul.
- Cross-module action: agenda ↔ task ↔ reminder, Inbox/Note/Project/Goal → task, task → agenda, automation.

## UI/UX
- Dashboard menjadi Mission Control.
- Chat menjadi chatbox minimal modern tanpa rail/sidebar padat.
- Ctrl+K label di TopBar dihapus.
- More sheet mobile memiliki logout.
- Search menjadi universal lintas lebih banyak modul.
- Settings menjadi Control Center dengan variabel AI/mobile/PWA yang lebih luas.
- Mobile hardening global + motion system.

## Catatan
Tidak ada integrasi pihak ketiga baru.
