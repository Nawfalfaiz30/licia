# Licia 0.48.0 — Chat, Navigation, Task Actions, Finance & Settings

## UI/UX
- Chat menjadi satu hierarki: header ringkas, percakapan, inline action receipt, dan satu composer.
- Footer ponsel memakai Lainnya sebagai katalog tujuan aktif.
- Navigasi desktop/mobile menggunakan workspace canonical yang sama.
- Notification panel memakai background solid agar tidak transparan terhadap dashboard.

## Planning
- Dashboard memisahkan query agenda hari ini dari agenda mendatang.
- Tombol prioritas, Agenda → Tugas, dan Tugas → Agenda tetap menjalankan aksi langsung dari workspace Tugas.

## Finance
- Langganan tetap dikelola dari Keuangan.
- Ringkasan komitmen rutin menampilkan ekuivalen bulanan/tahunan dan jumlah langganan aktif.

## Documentation & Settings
- Panduan pengguna mengikuti struktur workspace canonical dan tidak menampilkan label versi.
- Pengaturan mengikuti workspace gabungan dan mempertahankan kompatibilitas preferensi lama tanpa menampilkan menu teknis lama.
