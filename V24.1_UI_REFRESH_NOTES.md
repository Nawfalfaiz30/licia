# Licia V24.1 — UI/UX Refresh + AI Efficiency

Baseline: Licia V23.6 settings build-fix.

## UI/UX
- Dashboard rebuilt as an information-first Personal Home with direct-link information cards, priority/agenda/inbox/finance summaries, and a signal strip.
- Chat simplified into a normal modern chatbox. Guide and destructive actions are moved into a compact menu; message deletion remains subtle beside the timestamp.
- Mobile bottom navigation now shows exactly 5 visible destinations: Beranda, Hari Ini, Chat, Fokus, Lainnya. Life Command remains accessible from Lainnya.
- Universal Search mobile layout compacted: inline search row, icon submit, shorter header, tighter result cards.
- Smart Inbox mobile density improved: shorter capture/search/filter blocks and more compact triage suggestions/actions.
- Today page improved for mobile with current-active agenda card and tighter stats/timeline.
- Capture Studio redesigned and voice input hardened with microphone permission flow, Indonesian speech recognition, interim/final transcript handling, and clearer status/error feedback.
- Settings rewritten into a compact Control Center with appearance, background, AI controls, motion/PWA, workspace defaults, data export, system health, and mobile logout.
- Guide redesigned into a compact help center with searchable accordion sections and quick actions.

## Browser dialogs
- Removed application use of window.alert/window.confirm/window.prompt so local-host browser alert UI does not appear from app actions.
- Added custom ActionDialog/TextPromptDialog usage for destructive and text-entry confirmation flows.

## AI
- Unified all-data context remains available through read tools, but broad inline context is capped to reduce prompt tokens.
- `all` write requests now receive only cross-module/core write tools rather than every write tool schema.
- Chat history budget reduced and tool iteration limits tightened.
- Output token budget now follows response style: concise 420, normal 560, detailed 760.
- AI instructions continue to require tool verification for user data and real IDs/relations for cross-module actions.

## Validation
- TypeScript/TSX parser: 102 files, 0 syntax errors.
- Native alert/confirm/prompt usage in app/components: 0 (PWA installEvent.prompt is intentional browser API).
- Runtime source references to localhost:3000: 0.
- `globals.css` added only with actual newlines; balanced-brace check passed in prior refresh and V24.1 additions contain no literal escaped newlines.
- Full Next.js build is not claimed in the assistant container because project dependencies are not installed there. Run `npm install` + `npm run preflight` + `npm run verify` + `npm run build` locally.

## Important
- This release is LOCAL ONLY. Do not deploy to VPS until local build and manual smoke tests pass.
- Keep production `.env.local` / OpenAI credentials out of Git. Ensure the production OpenAI key is rotated if an older key was ever exposed.
